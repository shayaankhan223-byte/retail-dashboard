Retail Sales Performance & Analysis Dashboard

Major Assignment — Group of 3

Members: Hammadamjad, Ahsan Khan, Huzaifa Khan

Problem Statement

Retail businesses need quick insights into sales performance across categories, regions, and time.

Objective

  • Build an interactive dashboard for retail sales
  • Support any CSV dataset
  • Provide KPIs and visual analytics

Features

  • Login authentication
  • CSV upload (adaptive columns)
  • KPIs: total, orders, average, top group
  • Charts: bar, pie, trend line
  • Filters by category/region

Technology Stack

  • HTML, CSS, JavaScript
  • Chart.js for visualizations
  • GitHub Pages for hosting

Architecture

Client-side only: data parsed in browser, charts rendered dynamically. No backend required.

Demo

Live: https://shayaankhan223-byte.github.io/retail-dashboard/

Conclusion

Delivered an adaptive, modern, web-based retail analytics dashboard.
